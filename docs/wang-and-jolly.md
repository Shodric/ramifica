## How to load it

Manual wizard fields per scene: **title** (1-40), **direction**
(text for Spark to propose), **narrator line** (max 280, presents
the scene and ends with the question mirroring the options), **video prompt**
(Clip step) and, only in finals, **ending name** (max 40). Options
carry **label** (max 24) + icon + color. The root carries one extra
field: **image prompt** (Scenes step) describing **both** characters in
full — Wang and Jolly are unknown to the model, so the start frame
invents them and every clip inherits them from there. Every video
prompt opens from that frame (`Continuing from the opening frame…`)
and names both characters with their locked look.
